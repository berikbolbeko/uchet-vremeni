# Учет времени — веб-қосымша (PWA)

Mac-сыз, App Store-сыз және тегін жұмыс істейтін нұсқа. iPhone-да экранға орнатылады,
интернетсіз ашылады, деректер тек телефонда сақталады.

## Ішінде не бар

| Файл | Не істейді |
|---|---|
| `index.html` | Қосымшаның беті және төменгі табтар |
| `styles.css` | iOS стиліндегі дизайн (жарық және қараңғы тақырып) |
| `app.js` | Барлық логика: таймер, статистика, тарих, занятиелер, резервтік көшірме |
| `sw.js` | Офлайн режим: файлдарды телефонда сақтайды |
| `manifest.webmanifest`, `icons/` | Қосымшаның атауы мен иконкасы |

## iPhone-ға қалай орнатуға болады

Қосымша **HTTPS** арқылы ашылуы керек, сондықтан оны бір рет тегін хостингке салу керек.
Ең оңай жолы — **GitHub Pages** (git немесе бағдарлама орнатудың қажеті жоқ, бәрі браузерде):

1. https://github.com сайтында тегін аккаунт ашыңыз.
2. Жоғарғы оң жақтағы **+** → **New repository**. Атауы: `uchet-vremeni`, **Public** таңдаңыз → **Create repository**.
3. **uploading an existing file** сілтемесін басыңыз да, осы `pwa` папкасының **ішіндегі** барлық файлдар мен `icons` папкасын сүйреп әкеліңіз → **Commit changes**.
4. Репозиторийдің **Settings → Pages** бөлімі: *Source* = **Deploy from a branch**, *Branch* = **main**, папка **/ (root)** → **Save**.
5. 1–2 минуттан кейін сол бетте сілтеме шығады: `https://АККАУНТЫҢЫЗ.github.io/uchet-vremeni/`

Содан кейін iPhone-да:

1. Сілтемені **Safari**-де ашыңыз.
2. Төмендегі **«Поделиться»** (⬆︎) батырмасын басыңыз.
3. **«На экран „Домой“»** → **«Добавить»**.

Болды — экранда «Учет времени» иконкасы пайда болады. Бір рет ашқаннан кейін интернетсіз де жұмыс істейді.

> Репозиторий ашық (public) болғанымен, ол жерде тек қосымшаның коды тұрады.
> Сіздің жазбаларыңыз ешқайда жіберілмейді — олар тек телефонда сақталады.

## Түнгі ұйқы

«Сон» занятиесінде **🌙 Ночной сон** қосқышы қосулы тұрады. Ұйқы **22:00-де немесе одан кеш** басталса,
оның барлық уақыты **ояну күніне** жазылады. Мысалы, 22:30–07:00 ұйқысы толығымен келесі күнге
«8 ч 30 мин» болып түседі. 22:00-ден ерте басталған ұйқы түн ортасында екі күнге бөлінеді.
Бұл қосқышты кез келген занятиеге **Занятия** экранынан қосуға немесе өшіруге болады.

## Деректерді сақтау

- **Занятия → Сохранить резервную копию** — барлық деректерді `.json` файлына сақтайды («Файлы» немесе iCloud).
- **Занятия → Восстановить из копии** — сол файлдан қалпына келтіреді.
- Иконканы экраннан өшірсеңіз, деректер де өшеді — сондықтан анда-санда көшірме сақтап қойыңыз.

## Қосымшаны жаңарту

Файлдарды өзгерткен соң, `sw.js` ішіндегі `CACHE` нұсқасын арттырыңыз (`uchet-vremeni-v1` → `v2`)
да, GitHub-қа қайта жүктеңіз. Телефондағы қосымша жаңа нұсқаны келесі ашқанда алады.

## Компьютерде тексеру

```bash
python -m http.server 8765 --directory pwa
```

Содан кейін браузерде http://localhost:8765 ашыңыз.
